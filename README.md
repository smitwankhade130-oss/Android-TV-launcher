# Android-TV-launcher
Custom Android TV launcher built with Kotlin and Jetpack Compose. Tested on Android 9. Vibe coded with Claude.

My TV runs Android 9, has only 8 GB of storage, and a stripped-down settings app, so I couldn't debloat it or find a launcher I liked. So I built my own.

This is my first big project. I built it with Claude, vibe coding, and I'm upfront about that. I made the design decisions, tested everything on a real TV, and fixed what broke.

Section: What it does. The home screen has six main apps in a sliding row: YouTube, Netflix, JioHotstar, Spotify, Play Store, and Jellyfin. Below it there's an editable tagline, which can be a quote or a reminder, like doing your homework before watching TV. The Apps page shows every installed app, sorted into four tabs: All applications, Media, Games, and Tools. You can change the wallpaper on both pages, and pick any PNG as the screensaver. The screensaver starts after five minutes idle and stays off while a video is playing.

Section: Android 9 version. Built and tested only on Android 9. On other versions, some things, like the refresh button and input switching, may behave differently.

Section: What's next. This is version one, and I'm planning to keep upgrading it. The next big update is swappable home screen apps, so you can pick your own six. I'm aiming for the next few weeks, but no promises, since I'm learning as I build.
